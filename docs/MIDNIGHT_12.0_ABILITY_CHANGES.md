# World of Warcraft Midnight (12.0.0) Ability Changes

This document tracks all ability removals and additions in the Midnight expansion (version 12.0.0) for use in updating the keybinding system's ability database.

**Release Date:** Pre-patch January 20, 2026 | Full release March 2, 2026

## Overview

Midnight represents the largest ability pruning in WoW history, removing **100+ abilities** across all classes to reduce "button bloat" and improve gameplay clarity. Blizzard's goals:
- Reduce abilities that weren't meaningful or had too many modifiers
- Remove abilities that required addon/WeakAura tracking
- Make gameplay more approachable without losing depth

## Migration Notes

When migrating keybindings from The War Within (11.x) to Midnight (12.0):

1. **Abilities that were removed** should be flagged and removed from the keybinding
2. **Abilities that were renamed** should be updated to new names:
   - Devouring Plague → Shadow Word: Madness (Priest)
   - Shadow Crash → Tentacle Slam (Priest)
   - Void Bolt → Void Volley (during Voidform) (Priest)
   - Flame Shock → Voltaic Blaze (Elemental Shaman)
   - Malefic Rapture → removed, use Unstable Affliction stacking (Affliction Warlock)

3. **New core abilities** should be added:
   - Devourer spec (Demon Hunter)
   - Hatchet Toss (Survival Hunter)
   - Zenith (Windwalker Monk)
   - Shatter/Freezing system (Frost Mage)
   - And many more listed above

4. **Spec-specific abilities moved** to different trees need tracking
